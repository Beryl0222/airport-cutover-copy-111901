# 机场更换候机动线时的多语种旅客指引

候机区更换地面交通接驳动线时，旅客手里的旧指引（如“到东换乘后朝电梯走”）可能已失效，而现场两个楼层都挂着同名标牌。本工具是一个本地运行的 Node.js 多语种改线路径咨询系统：旅客用中英文描述自己看到的标识，系统给出当下可执行的一步，并在旅客继续询问、运营临时改线时保持指引与已确认进度相容。

所有记录、人员、地点和业务编号均为合成内容，仅使用 `data/inputs.json` 中的平面资料与问路记录。

## 数据字段

`signs` 给出标牌编号、楼层和现场展示文字（zh/en）。`corridors` 是允许通行的有向边，方向即允许通行方向，没有反向边即不能原路返回；`stepFree` 表示全段无阶差。`gates` 是只能单向通过、不能原路返回的闸口节点。`helpDesk` 是可辨认的求助点。`closures` 中 `notice` 是运营员提交的状态说明，`corridor` 是其关联通道。`sessions` 保存问路原句和最后确认为亲眼看到的标牌。`channels` 的长度以 Unicode 码点计算。

## 模块结构（`src/`，仅用 Node.js 标准库）

| 文件 | 职责 |
| --- | --- |
| `model.mjs` | 标牌、有向通道、单向闸口、封闭状态与路径搜索（BFS 最短路、全简单路径枚举） |
| `parser.mjs` | 规则式双语解析：目标、无障碍要求（硬约束/软偏好）、位置线索、闸口三态声明 |
| `session.mjs` | 会话状态机：位置三档（亲眼确认 / 按指引推断 / 同名未决）、安全已走路段、取消待下发 |
| `engine.mjs` | 路径引擎：可行性再核对、第一步一致性、封闭取消与替代、求助点回退 |
| `render.mjs` | 手机长文案与小屏分步短文案，按 Unicode 码点卡渠道预算，地标只引用资料挂牌文字/编号 |
| `i18n.mjs` | 两套语言的固定句式，不自造译名 |
| `audit.mjs` | 追加式审计（JSONL）：原话解析、下发步骤、被纠正的旧指引、换语言动作一致性 |
| `store.mjs` | 运行态快照（会话、运营变化），与只读资料分开落盘 |
| `app.mjs` | 编排层，供 CLI、演示与测试共用 |
| `cli.mjs` | 命令行入口 |
| `demo.mjs` | 五个关键场景的合成演练 |

## 关键设计纪律

- **位置三档**：`confirmed`（旅客亲眼读到编号/可唯一辨认标识）、`inferred`（按上一条指引推断）、`ambiguous`（同名地标或楼层未决）。同名“东换乘/East Transfer”在旅客自行报出楼层或编号前，系统不替其选择。
- **目的地不是位置**：旅客说“要去地面巴士/Coach”不会被当成已经站在 T18。
- **无障碍两档**：“带行李、尽量避开扶梯”是软偏好，可放行但如实标注；“No steps/全程无阶差/不能走楼梯”是硬约束，无合规路线时不引导有阶差通道，转为现场等候或求助点。
- **单向闸口不代认**：旅客不确定是否过闸时挂起，必须本人辨认闸后标牌；明确“还没过闸”才放行闸前指引，系统永远不主动声称旅客已过闸。
- **第一步一致才给步**：多条候选路径第一步完全一致且对本人可行时只发这一步；第一步分叉时先问现场可辨认标识。
- **改线再核对**：运营提交通道变化后，对所有在途会话重核；已确认安全走过的边保留，失效指引记录为待取消，旅客下次打开时随替代指引一次性下发明确的取消文字与原因，不重复打扰。
- **相反线索可纠正推断**：旅客读到与推断矛盾的标牌编号时，以亲眼证据为准纠正；但不能据此替旅客确认越过闸口。
- **文案不造词**：地标一律用资料里的现场挂牌文字或标牌编号；该语言下没有有据可查的短说法时，退化到编号或可辨认求助点。小屏缩短后仍保留影响方向、楼层或无障碍的事实。

## 运行

环境为 Node.js 22.23.4，零第三方依赖。

```sh
npm run inspect:data   # 列出资料记录数与字段完整性
npm run demo           # 五个合成场景的完整演练（含改线、取消、过闸、换语言）
npm test               # 资料完整性 + 16 项引擎/会话/渲染/审计测试
```

CLI（运行态写入 `runtime/`，已在 `.gitignore`；每次调用是独立进程，会自动恢复会话与审计）：

```sh
node src/cli.mjs ask <会话号> "<问路原话>" [--channel phone|small-zh|small-en]
node src/cli.mjs close <封闭号> --corridor <通道号> --notice "<说明>"
node src/cli.mjs open <封闭号>
node src/cli.mjs reverify
node src/cli.mjs explain <会话号>      # 回查原话解析、位置三档、下发步骤与取消记录
node src/cli.mjs stale                 # 所有被纠正的旧指引
node src/cli.mjs switch-lang <会话号> zh|en
node src/cli.mjs seed                  # 回放 data/sessions 的历史问路
```
